# Building a Cloud-Native CI/CD Pipeline Using Jenkins, Kubernetes, and GitOps

This repository contains a sample Flask app, Jenkins pipeline, Kubernetes manifests, Argo CD application, monitoring configs, and documentation to demonstrate a cloud-native CI/CD pipeline.

Structure:

 - /app - sample Flask app and Dockerfile
 - /ci-cd - Jenkinsfile and Trivy scan script
 - /k8s - Kubernetes manifests (namespace, deployment, service, RBAC)
 - /gitops - Argo CD Application manifest
 - /monitoring - Prometheus and Grafana artifacts
 - /docs - architecture, setup guide, final report
 - /slides - presentation outline

Replace placeholder values (YOUR_GITHUB_ORG, YOUR_IMAGE_REPO, YOUR_GITOPS_REPO) before using.
