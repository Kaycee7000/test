# Sound effects

`assets/sfx/whoosh/` holds short (0.3-0.8 s) transition whooshes/risers. One is placed just before each scene
cut at `render.sfx_db` (default -9 dB relative to the voice). Put 5-10 variations in the folder; one is picked per video.

Set `render.transition_sfx: false` to disable, or leave the folder empty.

Sources: YouTube Audio Library (sound effects tab), or any library licensed for commercial video use.
